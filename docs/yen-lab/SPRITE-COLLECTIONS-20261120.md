# Yên Lab • Supplemental sprite collection

Raw generated sprite sheets and extracted watercolor assets for **Yên Coffee & Tea**, **Positive Psychology**, **Walking & Exploring**, and **Breathing**.

- Source images preserved in `assets/sources/` (six original sheets).
- Extracted graphics in `assets/coffee-tea/`, `assets/positive-psychology/`, `assets/walking/`, and `assets/breathing/`.
- `manifest.json` documents provenance, source rectangles and 12 breathing animation frames.
- These are **review-only** assets, not live game animation or medically validated tools. Some crops retain partial neighboring details or painted background.
- For the breathing demo, frames remain a uniform 362×362; actual breathing seconds belong to the Yên Lab game timer and user-selected mode, not the sprite frame rate. Reduced motion must use a still image.
